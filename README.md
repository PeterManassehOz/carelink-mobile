# CareLink Mobile

CareLink is a React Native mobile healthcare appointment application built with Expo, TypeScript, Expo Router, and NativeWind.

## Features

- User registration and login
- JWT-based authentication
- Protected navigation
- Provider discovery
- Provider search
- Provider filtering
- Provider details
- Appointment booking
- Date and time selection
- Appointment confirmation
- Appointment management
- Appointment cancellation
- Profile editing
- Password change
- Light, dark, and system themes
- Loading, empty, and error states
- Persistent authentication state

## Tech Stack

- React Native
- Expo SDK 57
- TypeScript
- Expo Router
- NativeWind
- Context API
- Axios
- Expo SecureStore
